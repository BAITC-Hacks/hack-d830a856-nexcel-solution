# WindCast Agent

Почасовой прогноз нормализованной мощности двух ветротурбин для оператора ВЭС
на горизонте до 48 часов.

## Проблема

Оператору ВЭС нужен прогноз выработки, чтобы планировать баланс сети.
Проект воспроизводит прогноз исторически: погодные данные берутся из
архивного прогноза, а не из наблюдений, известных задним числом.

## SMART goal

S: прогнозировать нормализованную активную мощность двух турбин по часам.
M: на holdout за январь 2026 модель достигла MAE 0.2468 и RMSE 0.3004.
A: модель обучается на SCADA за 11.03.2023–31.01.2026 и прогнозах ECMWF IFS.
R: результат помогает оператору ВЭС планировать выработку на 24–48 часов.
T: к демо готов локальный пайплайн; walk-forward за февраль 2026 ждёт SCADA
за этот период.

## Architecture

SCADA XLSX/CSV → почасовой train set → архивная погода ECMWF IFS → физические
признаки → LightGBM → agent tools → LLM-ответ → FastAPI + HTML-консоль

## Quickstart

1. python -m venv .venv
2. .venv\Scripts\Activate.ps1
3. python -m pip install -r requirements.txt
4. python -m src.train.train_model
5. python -m src.app  (открыть http://127.0.0.1:7860)

Первый запуск обучения создаёт data/weather_cache/ и models/wind_power_lgb.pkl.
Для повторного обучения только из кэша используйте:
python -m src.train.train_model --offline.

Для LLM-диалога скопируйте .env.example в .env, укажите OPENAI_API_KEY и
установите MOCK_MODE=false. Без ключа интерфейс работает в demo-режиме.

## Why simple

LLM не считает мощность и не придумывает цифры. Он только вызывает два
явных инструмента: погоду и локальную модель. Поэтому физические ограничения,
метрики и результат воспроизводимы без LLM, а последовательность легко
объяснить судье.
