# WindCast Agent — почасовой прогноз выработки ВЭС

Agentic AI, который прогнозирует почасовую выработку 2 ветротурбин на 24-48 часов вперёд,
сам получая архивные прогнозы погоды по их координатам — для трека «Энергетика» HackAlem AI
(кейс Самрук-Казына).

## Проблема

Оператору ВЭС нужен прогноз выработки на 24-48ч вперёд, чтобы планировать баланс сети,
но у него нет системы, которая сама тянет погодные данные и пересчитывает прогноз без ручной работы.
Кейс требует воспроизвести это как if исторически: на каждую дату тестового периода (1-28 февраля 2026)
использовать только те архивные прогнозы погоды, что были доступны на тот момент, без забегания вперёд.

## Архитектура

```
turbine coords + история (data/) ──▶ src/weather/  ──▶ src/core/ (power curve → features → model) ──▶ прогноз
                                                                         ▲
                                              src/agents/ (LLM-оркестратор + tools) ── src/app.py (Gradio UI)
```

LLM в `src/agents/` только вызывает инструменты и объясняет результат — сам физику и цифры не считает
(см. `docs/skills/skill-agentic-loop.md`).

## Почему просто

Мы намеренно разделили детерминированное ядро (power curve + ML-модель, без LLM) и LLM-оркестратор,
который только вызывает готовые инструменты. Так физический расчёт остаётся воспроизводимым и
тестируемым без LLM в контуре, а агентная часть — это тонкий слой, который проще объяснить судье
за 2 минуты, чем один большой end-to-end чёрный ящик.
